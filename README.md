Crime Analysis Dashboard (Excel Project)
This project is an Excel-based dashboard focused on analyzing crime data across different regions. The idea was to visualize crime trends, highlight the most affected areas, and present the data in a clean, interactive way for better understanding.

What’s Inside:
Crime category-wise breakdown (like theft, assault, robbery etc.)

Year-wise and region-wise comparisons

Dynamic charts (bar, line, pie) for quick insights

Slicers and filters for easier interaction

Why I Made This:
I wanted to work on a real-world dataset and practice building a dashboard that could help identify patterns in crime rates. This project helped me apply data cleaning, visualization, and dashboarding skills in Excel.

Tools Used:
Microsoft Excel (PivotTables, Charts, Conditional Formatting, Slicers)
